# Libft

*Este proyecto ha sido creado como parte del currículo de 42 por ciparren*

## 📖 Descripción

**Libft** es el primer proyecto del *Common Core* de 42. Consiste en crear nuestra propia librería en C, reimplementando funciones estándar de la libc y añadiendo funciones adicionales útiles para la manipulación de cadenas, memoria y listas enlazadas.

Esta librería servirá como base para proyectos futuros en el cursus, por lo que es esencial que sea robusta, eficiente y esté bien documentada.



## 🎯 Objetivos

- Comprender el funcionamiento interno de las funciones estándar de C.
- Gestionar memoria correctamente (sin leaks).
- Trabajar con estructuras de datos (listas enlazadas).
- Escribir código siguiendo la **Norma** de 42.
- Crear un Makefile funcional y eficiente.

## 🛠️ Instrucciones de Compilación

### **Compilar la librería:**
make
